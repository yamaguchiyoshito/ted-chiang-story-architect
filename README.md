# Ted Chiang Story Architect

頭から離れない「一枚の絵」や「気になる考え」から、短編SF・哲学的フィクションの**設計図**（本文を書く前の骨格）を、Claude と対話しながら組み立てる Claude スキルです。テッド・チャンの創作手順（二項合成 → 因数分解 → 最短到達）を下敷きにしています。

本文は生成しません。生成するのは「何を問い、どう終わり、どの場面が必要か」を決めた設計図です。

## はじめて使う方へ

**まず [ユーザーガイド](docs/user-guide.md) を読んでください。** 物語を設計した経験がない方を前提に、ツールの操作より手前の考え方から説明しています。

## クイックスタート

1. このフォルダをスキルとして Claude に導入する（手順は [ガイド §4](docs/user-guide.md#4-導入)）
2. Claude に気になっている素材を一言で伝える
   > 例：「砂時計をひっくり返し続ける老人の画が頭から離れない。これを物語にしたい」
3. 「対話モード」を選び、3つの確認ポイント（ゲート）で選択・承認しながら進める

## ファイル構成

| パス | 内容 |
|---|---|
| `SKILL.md` | スキル本体（Claude が読む手順書） |
| `references/` | 各ステップの詳細手順・変数定義・テッド・チャンの実例（Claude が読む） |
| `docs/user-guide.md` | 利用者向けガイド（人が読む） |
