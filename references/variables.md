# 変数仕様リファレンス

各変数の定義・判定基準・失敗パターンを記述する。

> 凡例：像A × 概念B → 核K ／ 核K → 問いQ・結末E・機構M・主人公H・語りN ／ 粘着R＝素材フィルター
> セクションの並びは確定順序（粘着R → 像A・概念B → 核K → 問いQ → 結末E → 機構M → 主人公H → 語りN）に揃えている。

---

## 粘着R：回帰アイデア選別

**位置づけ**
第0段階の入口フィルター。因数分解の確定順序には含まれない。

**定義**
著者の観念に「粘着」して繰り返し脳内に戻ってくるコンセプト。価値の高低ではなく「再帰性」が基準。

**機能**
粘着Rはアイデアの入口であり、フィルターである。何年も頭に残っているコンセプトだけが核Kの素材になる資格を持つ。

**操作方法**
ユーザーの入力から「繰り返し言及されている」「強調されている」「最初に出てきた」要素を抽出し、粘着Rとして提示する。ユーザーが明示しない場合は確認する。

---

## 像A：Iconic Image

**定義**
1シーンで完結する具体像。装置・行為・状況・語り口の形式そのもの。「これだけで読者の感覚が刺さる」絵。

**条件**
- 説明なしに視覚化できる
- 読者の感覚・情動に直接作用する（概念を経由しない）
- 語り口の「形式」も像になりうる（例：娘への語りかけという語り口そのものが像）

**失敗パターン**
- 「孤独な科学者」「愛し合う二人」──抽象的すぎて視覚化できない
- テーマの言い換えになっている（像Aが「喪失」→ 概念Bも問いQも全部「喪失」になる）
- シーンではなく状況説明になっている

---

## 概念B：Constraint / Argument

**定義**
科学・哲学・制度・認知の「避けられない含意」。逃げ道のない制約・議論・法則。「読者の思考を追い込む」命題。

**条件**
- 命題として1文に圧縮できる
- 「もしこれが真なら〜せざるをえない」という強制力を持つ
- 著者が本当に関心を持っている問題系から来ている（表面的な流用は壊れる）

**候補領域**
- 物理・数学の原理（変分原理、熱力学第二法則、ゲーデルの不完全性定理）
- 認知科学（サピア＝ウォーフ仮説、エピソード記憶の限界、自由意志の両立論）
- 制度・倫理（能力強化とメリトクラシーの前提、記録と記憶の乖離）
- 存在論（時間の方向性、個体同一性、意識のハード問題）

**失敗パターン**
- 「テクノロジーの進化」「人間の欲望」──回避可能な観察であり、制約ではない
- 像Aとの接触を持たない純粋な論文命題
- 著者が「クールだから」選んだだけで追い込まれていない

## 核K：Nucleus（物語核）

**定義**
核K = 像A × 概念B。像Aと概念Bの衝突から、問いQと「誰が最も損をするか（主人公H）」が自然に立ち上がる状態。

**衝突判定**
衝突は「混在」ではなく「矛盾を含む接触」。

| パターン | 判定 |
|---|---|
| 像Aが概念Bを例示している | ❌ 混在（論文になる） |
| 像Aが概念Bによって不可能になる | ✅ 衝突 |
| 像Aが概念Bを逆説的に肯定する | ✅ 衝突 |
| 像Aと概念Bが同じ方向を指している | ❌ 混在 |

**チェック**
核K = 像A × 概念B が成立したとき、次の2つが自然に立ち上がるか確認する：
- **問いQ**：この衝突が生む「避けられない問い」
- **主人公H**：この衝突において「最も損をする立場」

どちらかが不自然なら、像Aか概念Bのどちらかが弱い。

---

## 問いQ：哲学的問い

**定義**
作品全体を貫く問い。疑問文1行に圧縮される。

**形式**
- 「〜は成立するのか」
- 「〜できるのか」
- 「〜は何を意味するのか」
- **禁止**：「AかBか」「どちらが正しいか」──二択は問いQではなく議論のフレームになる

**絞り込み基準**
候補が複数ある場合、次で絞る：
1. 結末Eが問いQへの直接の「回答」になっているか
2. 語りNが問いQを読者に「体験」させられるか
3. 主人公Hが問いQの最大の当事者になっているか

3つすべてを満たす問いだけが残る。

**失敗パターン**
- 「自由意志とは何か」──広すぎて1作品では回答不能
- 「AIは意識を持てるか」──YesかNoかの答えを求める問いになっている
- 結末Eと整合しない問い（問いへの回答が結末に現れない）

---

## 結末E：結末段落

**定義**
著者が問いQに対して「同意できる回答」を100〜200字で述べた段落。先に書き、固定する。

**「同意できる」の意味**
読者を慰める結論ではなく、著者自身が倫理的に署名できる結論。テッド・チャンはこれを設計条件とする。
このスキルの運用では「著者」＝ユーザーであるため、結末Eの確定には必ずユーザーの承認を得る。

**結末Eの構造**
- 問いQへの直接の回答を含む
- 喪失や矛盾が消えるのではなく、**含む全体を引き受ける**形をとる
- 感情的納得と概念的納得が同時に起こるよう書く

**操作方法**
1. 問いQを1行で書く
2. 「著者として同意できる答え」を1〜2文で書く
3. それを100〜200字の段落に展開する

**失敗パターン**
- 「問いに答えず、余韻で終わる」── 結末Eは問いQへの回答である
- 「ハッピーエンドの定型句」── 読者への配慮が問いQへの回答より優先している
- 本文を書いてから結末Eを書く── 軌道が決まってから境界条件を設定するのは逆

## 機構M：世界の機構（ルールセット）

**定義**
問いQを成立させる最小の物理・社会・認知ルール。3制約に絞る。

**3制約の構造**

| 制約 | 内容 | 例（あなたの人生の物語） |
|---|---|---|
| ①観測制約 | 何が見える/見えないか | 言語習得により時間が「全体同時」に見える |
| ②因果制約 | 何が何を引き起こすか | 終点を知ることで選択の意味が変わる |
| ③コスト制約 | 何を犠牲にするか | 知りながら愛着を持ち続けるコスト |

**探索と棄却の方法**
テッド・チャン自身は複数案を順に棄却した（未来知の獲得方法：薬物→瞑想→言語習得）。機構Mの選定には必ず複数案の棄却を行い、採用理由を明示する。

**棄却の判定基準**
- 問いQを成立させられるか
- 主人公Hの「損」を最大化するか
- 語りNで機構Mを「体験」させられるか

**注意**
SFジャンルは機構Mが決まった後に選ぶ。機構Mを説明可能にする最適な舞台として選ばれる。ジャンル先行は設計の逆転。

## 主人公H

**定義**
「この世界で最も損をする立場」の人物。1人に絞る。

**損の定義**
事件の悲惨さではなく、**知っていても愛着を引き受け続けること**が「損」の正体。これがプロットのエンジンになる。

**強度の段階確認（必須）**
採用前に必ず以下の段階表を作成する：

```
弱   ：結婚→離婚（回避可能な損）
中   ：結婚相手の死（一方的な喪失）
採用 ：子の死（不可避な喪失と不可避な喜びの同時引受）
```

「採用水準」とは「損の不可避性とコストが最大化されている」状態。

**失敗パターン**
- 「普通の人間」── 問いQへの当事者性がない
- 損が「外部から与えられた不幸」のみ──愛着を引き受けるという内的コストがない
- 問いQと関係のない悲惨さを持つ人物

## 語りN：語り装置

**定義**
語りNは機構Mの説明装置ではなく、**機構Mを読者に体験させる装置**。語り口の選択そのものが問いQの体験を構成する。

**選択肢**

| 形式 | 機能 | 適する問いQのタイプ |
|---|---|---|
| 1人称現在進行 | 読者を主人公の認知に同期させる | 知覚・認知の変容を問う問いQ |
| 未来から書く手紙 | 時間の方向を逆転させる | 知っていても行為するとはどういうことかを問う問いQ |
| 全体同時提示 | 時間を「軌道全体」として経験させる（変分原理的） | 喪失と肯定の同時性を問う問いQ |
| 交互配置 | 認知の足場を二重化する | 概念と感情の両方を当事者として体験させる問いQ |

**絶対ルール**
- 1つに固定する。混ぜると問いQが死ぬ
- 「語りやすいから」という理由で選ばない。語りNは問いQと結末Eから逆算して選ぶ

**整合チェック（問いQ・結末E・語りN 三角形）**
語りNが問いQへの結末Eの回答を読者に体験させられるか。この三角形が崩れる設計は構造的失敗。

## 変更影響マトリクス

部分修正の依頼を受けたとき、変更した変数ごとに以下の項目を再チェックする。影響範囲外の変数は変更しない。

| 変更した変数 | 再チェックが必要な項目 |
|---|---|
| 像A / 概念B | 核Kの衝突判定からすべてやり直し（以降の全変数に波及） |
| 核K | 問いQ・主人公Hが自然に立ち上がるか → 立ち上がらなければ以降すべて再設計 |
| 問いQ | 結末Eが回答になっているか／語りNが体験させられるか／主人公Hの当事者性 |
| 結末E | 問いQとの整合／最短到達チェックの必要シーン／語りNの逆算 ＋ ユーザー承認の再取得 |
| 機構M | 問いQの成立／主人公Hの損の最大化／語りNの体験可能性／SFジャンル（舞台）の再選定 |
| 主人公H | 損の強度段階表の再作成／結末Eに署名できるか（当事者が変わると回答も変わりうる） |
| 語りN | 問いQ・結末E・語りN三角形の整合のみ（他変数への影響は小さい） |
